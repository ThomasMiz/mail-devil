# Mail Devil

Mail Devil is a simple POP3 server, continuing [Dust Devil](https://github.com/ThomasMiz/dust-devil)'s trend of implementing simple networking protocols using [Rust](https://www.rust-lang.org/).

The goal of this project was to learn about the Post Office Protocol - Version 3, defined by [RFC 1939](https://www.rfc-editor.org/rfc/rfc1939), and understand the challenges it poses to implementations as well as server performance characteristics.

Being one of the teachers of the course 72.07 - Protocolos de Comunicación ("Communication Protocols") in the ITBA (Instituto Tecnológico de Buenos Aires), I was going to be correcting the group projects which consist of implementing a server for said protocol. However, since I had never worked with POP3, I decided to implement one myself to give me the knowledge necessary for the task.
